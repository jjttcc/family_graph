# Commit Standards: family_graph

To maintain a clean and readable commit history, all commit messages must adhere 
to the following standards:

1. Subject Line:
   - Maximum 50 characters.

2. Body:
   - Paragraphs are used to delineate different points.
   - Do NOT use bullet points (no lines starting with "  - ").
   - Maximum 70 characters per line.
   - Paragraphs must be separated by a single empty line ("\n\n").
   - There must be no lines containing only spaces.
